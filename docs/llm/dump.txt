# Network Monitor

Cross-platform network health monitor built with .NET 11 / C# 15. Pings your router, an internet target, and any number of custom hosts; stores every cycle in SQLite; optionally replicates hourly rollups to Turso/libSQL and Databricks.

> **AI-assisted development notice:** this codebase, including its architecture and documentation, was produced through extensive collaboration with Claude by Anthropic.

## Features

- At-a-glance health: Excellent / Good / Degraded / Poor / Offline
- Auto-detected gateway and internet target, with manual overrides
- Per-lookup DNS timeout, so a dead resolver cannot stall the cycle
- SQLite history (WAL, normalized schema, automatic retention)
- Optional, fault-tolerant rollup sync to Turso/libSQL and Databricks
- OpenTelemetry metrics written to rotating JSON files
- Self-contained single-file binaries for Windows, macOS, Linux (x64, ARM64)

## Quick Start

Prerequisite: .NET 11 SDK. `global.json` accepts `11.0.100-rc.3` or any later 11.0 SDK, so RC3 works locally while CI uses the latest GA.

```bash
git clone https://github.com/kusl/NetworkMonitor.git
cd NetworkMonitor/src
./run.sh            # build + run
./run.sh --test     # tests
../verify.sh        # layout check + restore + build + test summary
```

Tests run on Microsoft.Testing.Platform: `dotnet test --solution src/NetworkMonitor.slnx`.

## Configuration

`appsettings.json` next to the executable, or environment variables (`NetworkMonitor__IntervalMs=10000`). The file is resolved from the executable's directory, not the working directory.

| `NetworkMonitor` option | Default | Notes |
|---|---|---|
| `RouterAddress` | `auto` | Explicit IP disables auto-detection |
| `InternetTarget` | `8.8.8.8` | Primary internet target |
| `TimeoutMs` | `3000` | Per ping and per DNS lookup (min 100) |
| `IntervalMs` | `5000` | Start-to-start cycle interval (min 250) |
| `PingsPerCycle` | `3` | 1–20 |
| `ExcellentLatencyMs` | `20` | |
| `GoodLatencyMs` | `200` | |
| `DegradedPacketLossPercent` | `10` | |
| `EnableFallbackTargets` | `true` | Try other public resolvers if the primary is unreachable |
| `EnableIPv6` | `true` | IPv4 is always preferred; IPv6 only when no IPv4 address exists |
| `EnableDnsChecks` | `true` | Record DNS timing for hostname targets |
| `QuietConsole` | `true` | Healthy cycles overwrite one line; problems scroll |
| `MaxConcurrentChecks` | `6` | Parallel target probes per cycle |
| `CustomTargets` | list | `{ "Name", "Address", "Enabled" }` |
| `DisabledChecks` | `[]` | Names to skip, e.g. `Router`, `Internet`, a custom name |

| `Storage` option | Default |
|---|---|
| `DatabaseFileName` | `network-monitor.db` |
| `DataDirectoryOverride` | empty |
| `RetentionDays` | `30` |

## Health

Internet latency is the primary signal. A slow router reply alone never lowers health (routers de-prioritize ICMP on their control plane); it is annotated instead, and only counts when the internet is also slow.

| State | Meaning |
|---|---|
| Excellent | Internet ≤ `ExcellentLatencyMs` |
| Good | Internet ≤ `GoodLatencyMs` |
| Degraded | Packet loss, router down while internet up, or slow internet and slow router |
| Poor | Router up but internet down or slow |
| Offline | Internet unreachable |

## Data

Location: `$XDG_DATA_HOME/NetworkMonitor`, else `%LOCALAPPDATA%\NetworkMonitor` / `~/.local/share/NetworkMonitor`.

SQLite tables (unchanged since the normalized schema was introduced):

- `targets(id, name, address, category)` unique on `(address, category)`; category is `router`, `internet`, or `custom`
- `monitor_cycles(id, ts_ms, health, message)`
- `check_results(cycle_id, target_id, success, rtt_ms, rtt_min_ms, rtt_max_ms, jitter_ms, dns_ms, loss_pct, resolved_ip, error_message)`
- `sync_state(key, value)` holding `remote_rollup_next_bucket_ms` and `databricks_rollup_next_bucket_ms`

`resolved_ip` is the address that was actually pinged for hostname targets.

Telemetry: `<data>/telemetry/metrics_<runId>.json`, rotating to `metrics_<runId>_001.json`, `_002`, … at 25 MB or UTC midnight.

## Remote Sync

Both sinks ship one rollup row per target per closed bucket, keyed by `(machine, target_address, bucket_start)`, so re-sends are idempotent. Each is a no-op when unconfigured, retries silently, and can never interrupt monitoring.

Shared options for `RemoteSync` and `Databricks`: `BucketMinutes` (60), `SyncIntervalMinutes` (60, min 5), `InitialDelaySeconds`, `BatchSize`, `MaxRowsPerSync` (25000), `RequestTimeoutSeconds`.

**Turso / libSQL** (`RemoteSync`): `Url` (`libsql://`, `https://`, `wss://`), `AuthToken`, `TableName` (`check_rollups`). Defaults: delay 60 s, batch 500, timeout 30 s.

**Databricks** (`Databricks`): `WorkspaceUrl`, `WarehouseId`, `Catalog` (`workspace`), `Schema` (`default`), `TableName` (`network_monitor_rollups`), and either `Token` or `ClientId` + `ClientSecret` (OAuth M2M). `StatementWaitSeconds` 5–50. Defaults: delay 90 s, batch 200, timeout 120 s. Rows are written with `MERGE INTO` in batches of 30.

Prefer environment variables for secrets: `RemoteSync__AuthToken`, `Databricks__ClientSecret`.

## Metrics

Meter `NetworkMonitor.Core`: `network_monitor.checks`, `.failures`, `.router_latency_ms`, `.internet_latency_ms`, `.dns_resolution_ms`, `.packet_loss_percent`, `.jitter_ms`, plus .NET runtime metrics.

## Engineering Notes

- `net11.0`, C# 15 (union types, collection expression arguments), C# 14 extension members and `field`-backed option validation
- `TreatWarningsAsErrors`, `AnalysisLevel=latest-recommended`, `InvariantGlobalization`
- Central package management; dependencies: `Microsoft.Extensions.Hosting`, `Microsoft.Data.Sqlite`, `OpenTelemetry.Extensions.Hosting`, `OpenTelemetry.Instrumentation.Runtime`, `xunit.v3`
- Banned: Moq, FluentAssertions, MassTransit
- `TimeProvider` and `IMeterFactory` injected everywhere time or metrics are involved

- **Build and Test**: Ubuntu, Windows, macOS on every push and PR
- **Build and Release**: tests, then self-contained single-file binaries for six RIDs with `SHA256SUMS.txt`; binaries carry the release version
- **Dependency Check**: weekly outdated/vulnerable/deprecated report
- **Dependabot**: NuGet and Actions

## Troubleshooting

- Linux ICMP permission errors: `sudo setcap cap_net_raw+ep ./NetworkMonitor.Console`
- Wrong gateway on machines with many virtual adapters: set `RouterAddress` explicitly
- `.NET 11` requires x86-64-v2 on x64 and LSE on Windows Arm64

#!/usr/bin/env bash
#
# Export project source into a single, self-describing text file.
#
# Improvements over the previous POSIX version:
#   * Uses `git ls-files` (tracked + untracked-but-not-ignored) for an accurate,
#     reproducible file list, with a `find` fallback outside a git checkout.
#   * NUL-safe throughout (handles paths with spaces or newlines).
#   * Records per-file SHA-256, byte size, and line count, plus a header with
#     the git commit, branch, generation time, dotnet version, and totals.
#   * Includes shell (.sh) and Markdown (.md) files, which the old exporter
#     skipped, so docs and scripts are captured too.
#   * Emits a SHA-256 of the finished dump so its integrity can be verified.
#
# Usage: ./export.sh [PROJECT_PATH] [OUTPUT_FILE]
#   PROJECT_PATH  defaults to the script's own directory
#   OUTPUT_FILE   defaults to docs/llm/dump.txt (relative to PROJECT_PATH)

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

PROJECT_PATH="${1:-$SCRIPT_DIR}"
OUTPUT_FILE="${2:-docs/llm/dump.txt}"

# Extensions to include.
INCLUDE_EXTENSIONS="cs json xml csproj sln slnx props config cshtml razor js css scss html yml yaml sql sh md"

# Directory names to exclude anywhere in the tree.
EXCLUDE_DIRS="bin obj .vs .git node_modules packages .vscode .idea docs"

# Resolve to an absolute path and work from there so all paths are relative.
PROJECT_PATH="$(cd "$PROJECT_PATH" && pwd)"
cd "$PROJECT_PATH"

OUTPUT_PATH="$PROJECT_PATH/$OUTPUT_FILE"
OUTPUT_DIR="$(dirname "$OUTPUT_PATH")"
mkdir -p "$OUTPUT_DIR"

# Path of the output file relative to the project root (for self-exclusion).
OUTPUT_REL="${OUTPUT_PATH#"$PROJECT_PATH"/}"

# Colours only when writing to a terminal.
if [ -t 1 ]; then
    GREEN='\033[0;32m'; YELLOW='\033[0;33m'; CYAN='\033[0;36m'; NC='\033[0m'
else
    GREEN=''; YELLOW=''; CYAN=''; NC=''
fi
log() { printf "%b%s%b\n" "$1" "$2" "$NC"; }

# --- portable helpers --------------------------------------------------------

sha256_of() {
    if command -v sha256sum >/dev/null 2>&1; then
        sha256sum "$1" | awk '{print $1}'
    elif command -v shasum >/dev/null 2>&1; then
        shasum -a 256 "$1" | awk '{print $1}'
    else
        printf 'unavailable'
    fi
}

mod_time_of() {
    if stat --version >/dev/null 2>&1; then
        stat -c '%y' "$1" 2>/dev/null | cut -d'.' -f1
    else
        stat -f '%Sm' -t '%Y-%m-%d %H:%M:%S' "$1" 2>/dev/null
    fi
}

has_included_extension() {
    local ext="${1##*.}"
    [ "$ext" != "$1" ] || return 1
    local inc
    for inc in $INCLUDE_EXTENSIONS; do
        [ "$ext" = "$inc" ] && return 0
    done
    return 1
}

is_in_excluded_dir() {
    local path="$1" dir
    for dir in $EXCLUDE_DIRS; do
        case "$path" in
            "$dir"/*|*/"$dir"/*) return 0 ;;
        esac
    done
    return 1
}

in_git_repo() { git rev-parse --is-inside-work-tree >/dev/null 2>&1; }

# --- gather the file list (NUL-delimited) ------------------------------------

log "$GREEN" "Starting project export..."
log "$YELLOW" "Project Path: $PROJECT_PATH"
log "$YELLOW" "Output File:  $OUTPUT_PATH"

RAW_LIST="$(mktemp)"
FILE_LIST="$(mktemp)"
trap 'rm -f "$RAW_LIST" "$FILE_LIST"' EXIT

if in_git_repo; then
    log "$CYAN" "Listing files via git..."
    git ls-files -z --cached --others --exclude-standard > "$RAW_LIST"
else
    log "$YELLOW" "Not a git repo; falling back to find..."
    find . -type f -print0 > "$RAW_LIST"
fi

# Filter: drop excluded dirs, the output file itself, and non-included types.
while IFS= read -r -d '' file; do
    rel="${file#./}"
    [ "$rel" = "$OUTPUT_REL" ] && continue
    is_in_excluded_dir "$rel" && continue
    has_included_extension "$rel" || continue
    printf '%s\0' "$rel"
done < "$RAW_LIST" | LC_ALL=C sort -z -u > "$FILE_LIST"

FILE_COUNT=0
while IFS= read -r -d '' _; do FILE_COUNT=$((FILE_COUNT + 1)); done < "$FILE_LIST"
log "$GREEN" "Found $FILE_COUNT files to export"

# --- header ------------------------------------------------------------------

GIT_COMMIT="n/a"; GIT_BRANCH="n/a"
if in_git_repo; then
    # --verify --quiet prints nothing (rather than echoing "HEAD") when there
    # is no commit yet, so an unborn branch does not corrupt the header.
    commit="$(git rev-parse --verify --quiet HEAD 2>/dev/null || true)"
    [ -n "$commit" ] && GIT_COMMIT="$commit"
    branch="$(git branch --show-current 2>/dev/null || true)"
    [ -n "$branch" ] && GIT_BRANCH="$branch"
fi
DOTNET_VERSION="$(dotnet --version 2>/dev/null || echo 'not installed')"

{
    echo "==============================================================================="
    echo "PROJECT EXPORT"
    echo "Generated (UTC): $(date -u '+%Y-%m-%d %H:%M:%S')"
    echo "Project Path:    $PROJECT_PATH"
    echo "Git Commit:      $GIT_COMMIT"
    echo "Git Branch:      $GIT_BRANCH"
    echo ".NET SDK:        $DOTNET_VERSION"
    echo "Files Exported:  $FILE_COUNT"
    echo "==============================================================================="
    echo
    echo "DIRECTORY STRUCTURE:"
    echo "==================="
    echo
} > "$OUTPUT_PATH"

if command -v tree >/dev/null 2>&1; then
    TREE_IGNORE="$(echo "$EXCLUDE_DIRS" | tr ' ' '|')"
    tree -a -I "$TREE_IGNORE" --noreport >> "$OUTPUT_PATH" 2>/dev/null || true
else
    while IFS= read -r -d '' rel; do
        depth="$(printf '%s' "$rel" | tr -cd '/' | wc -c | tr -d ' ')"
        indent=""; i=0
        while [ "$i" -lt "$depth" ]; do indent="$indent    "; i=$((i + 1)); done
        printf '%s+-- %s\n' "$indent" "$(basename "$rel")" >> "$OUTPUT_PATH"
    done < "$FILE_LIST"
fi

printf '\n\n' >> "$OUTPUT_PATH"

# --- file contents -----------------------------------------------------------

{
    echo "FILE CONTENTS:"
    echo "=============="
    echo
} >> "$OUTPUT_PATH"

TOTAL_BYTES=0
CURRENT=0
while IFS= read -r -d '' rel; do
    CURRENT=$((CURRENT + 1))
    full="$PROJECT_PATH/$rel"
    [ -f "$full" ] || continue

    size="$(wc -c < "$full" | tr -d ' ')"
    lines="$(wc -l < "$full" | tr -d ' ')"
    size_kb="$(awk "BEGIN {printf \"%.2f\", $size / 1024}")"
    hash="$(sha256_of "$full")"
    modified="$(mod_time_of "$full")"
    TOTAL_BYTES=$((TOTAL_BYTES + size))

    log "$CYAN" "Processing ($CURRENT/$FILE_COUNT): $rel"

    {
        echo "================================================================================"
        echo "FILE:     $rel"
        echo "SIZE:     ${size_kb} KB (${size} bytes)"
        echo "LINES:    $lines"
        echo "SHA256:   $hash"
        echo "MODIFIED: $modified"
        echo "================================================================================"
        echo
    } >> "$OUTPUT_PATH"

    if [ -s "$full" ]; then
        cat "$full" >> "$OUTPUT_PATH" 2>/dev/null || echo "[ERROR READING FILE]" >> "$OUTPUT_PATH"
    else
        echo "[EMPTY FILE]" >> "$OUTPUT_PATH"
    fi

    printf '\n\n' >> "$OUTPUT_PATH"
done < "$FILE_LIST"

TOTAL_MB="$(awk "BEGIN {printf \"%.2f\", $TOTAL_BYTES / 1048576}")"

# --- footer ------------------------------------------------------------------

{
    echo "==============================================================================="
    echo "EXPORT COMPLETED (UTC): $(date -u '+%Y-%m-%d %H:%M:%S')"
    echo "Total Files Exported:   $FILE_COUNT"
    echo "Total Source Size:      ${TOTAL_MB} MB (${TOTAL_BYTES} bytes)"
    echo "Output File:            $OUTPUT_PATH"
    echo "==============================================================================="
} >> "$OUTPUT_PATH"

# Self-hash: covers everything written so far (i.e. the whole file except the
# single line we are about to append). Verify with:
#   head -n -1 dump.txt | sha256sum
DUMP_HASH="$(sha256_of "$OUTPUT_PATH")"
echo "DUMP SHA256 (of all lines above this one): $DUMP_HASH" >> "$OUTPUT_PATH"

log "$GREEN" ""
log "$GREEN" "Export completed successfully!"
log "$YELLOW" "Output file: $OUTPUT_PATH"
log "$CYAN" "Total source size: ${TOTAL_MB} MB across ${FILE_COUNT} files"

        AppendStatusCell(sb, status.Router);
        sb.Append(Ansi(Cyan)).Append("Internet:").Append(Ansi(Reset)).Append(' ');
        AppendStatusCell(sb, status.Internet);

        List<TargetCheckResult> custom = [.. status.Custom];
        if (custom.Count > 0)
        {
            var ok = custom.Count(r => r.Success);
            var customColor = ok == custom.Count ? Green : ok > 0 ? Yellow : Red;
            sb.Append(Ansi(Cyan)).Append("Targets:").Append(Ansi(Reset)).Append(' ')
              .Append(Ansi(customColor)).Append(CultureInfo.InvariantCulture, $"{ok}/{custom.Count}").Append(Ansi(Reset)).Append(' ');
        }

        sb.Append(Ansi(Magenta)).Append(CultureInfo.InvariantCulture, $"[{status.Timestamp.ToLocalTime():HH:mm:ss}]").Append(Ansi(Reset));

            sb.Append(Ansi(Dim)).Append("  --  ").Append(Ansi(Reset));

                break;
            case { Success: true } dns:

                  .Append(' ').Append(Ansi(Dim)).Append(CultureInfo.InvariantCulture, $"FAIL: {result.Error ?? "No response"}").Append(Ansi(Reset));

                  .Append(' ').Append(Ansi(Dim)).Append(parts.Count > 0 ? string.Join(", ", parts) : "degraded").Append(Ansi(Reset));
            }

            if (result.Dns is { Success: false })
            {

            }
        }

        result.LatencyMs > _options.GoodLatencyMs ||

namespace NetworkMonitor.Core.Display;

public sealed class LiveConsole(TextWriter output, bool ansiEnabled)
{
    private const string SaveCursor = "\x1b[s";
    private const string RestoreCursor = "\x1b[u";
    private const string EraseToEndOfScreen = "\x1b[J";

    private readonly Lock _gate = new();
    private bool _transientParked;

    public LiveConsole()
        : this(Console.Out, !Console.IsOutputRedirected)
    {
    }

    public bool AnsiEnabled => ansiEnabled;

    public void WriteTransientLine(string text)
    {
        ArgumentNullException.ThrowIfNull(text);
        lock (_gate)
        {
            ClearParkedLine();
            if (ansiEnabled)
            {
                output.Write(SaveCursor);
                output.Write(text);
                _transientParked = true;
            }
            else
            {
                output.Write(text);
                output.Write('\n');
            }

            output.Flush();
        }
    }

    public void WriteBlock(string text)
    {
        ArgumentNullException.ThrowIfNull(text);
        lock (_gate)
        {
            ClearParkedLine();
            output.Write(text);
            if (!text.EndsWith('\n'))
            {
                output.Write('\n');
            }

            output.Flush();
        }
    }

    public void Reset()
    {
        lock (_gate)
        {
            ClearParkedLine();
            output.Flush();
        }
    }

    private void ClearParkedLine()
    {
        if (_transientParked)
        {
            output.Write(RestoreCursor);
            output.Write(EraseToEndOfScreen);
            _transientParked = false;
        }
    }
}

    {

        ArgumentNullException.ThrowIfNull(options);

        if (internet is not null)
        {
            return EvaluateInternet(router, internet, options);
        }

        if (router is not null)
        {
            return EvaluateRouterOnly(router, options);
        }

        return EvaluateCustom(custom);
    }

    private static (NetworkHealth, string) EvaluateInternet(
        TargetCheckResult? router,
        TargetCheckResult internet,
        MonitorOptions options)
    {
        var routerReachable = router is { Success: true };
        var routerDown = router is { Success: false };
        var routerLatency = router?.LatencyMs ?? 0;
        var routerSlow = routerReachable && routerLatency > options.GoodLatencyMs;

        if (!internet.Success)
        {
            return routerReachable ? (NetworkHealth.Poor, "Router OK but cannot reach internet")
                : routerDown ? (NetworkHealth.Offline, "Cannot reach router or internet")
                : (NetworkHealth.Offline, "Cannot reach internet");
        }

        if (internet.PacketLossPercent >= options.DegradedPacketLossPercent)
        {
            return (NetworkHealth.Degraded, $"High internet packet loss: {internet.PacketLossPercent:F0}%");
        }

        if (routerDown)
        {
            return (NetworkHealth.Degraded, "Internet OK but cannot reach router");
        }

        var routerNote = routerSlow
            ? $" (router replies slowly: {routerLatency}ms - likely ICMP de-prioritization, not a path problem)"
            : string.Empty;
        var latency = internet.LatencyMs ?? 0;

        if (latency <= options.ExcellentLatencyMs)
        {
            return (NetworkHealth.Excellent, $"Excellent - Internet: {latency}ms{routerNote}");
        }

        if (latency <= options.GoodLatencyMs)
        {
            return (NetworkHealth.Good, $"Good - Internet: {latency}ms{routerNote}");
        }

        return routerSlow
            ? (NetworkHealth.Degraded, $"High latency on internet ({latency}ms) and router ({routerLatency}ms) - possible local Wi-Fi/link issue")
            : (NetworkHealth.Poor, $"High internet latency: {latency}ms - likely upstream/ISP");
    }

    private static (NetworkHealth, string) EvaluateRouterOnly(TargetCheckResult router, MonitorOptions options)
    {
        if (!router.Success)
        {
            return (NetworkHealth.Offline, "Cannot reach router (internet check disabled)");
        }

        if (router.PacketLossPercent >= options.DegradedPacketLossPercent)
        {
            return (NetworkHealth.Degraded, $"Router packet loss: {router.PacketLossPercent:F0}% (internet check disabled)");
        }

        return (NetworkHealth.Good, $"Router reachable: {router.LatencyMs ?? 0}ms (internet check disabled)");
    }

    private static (NetworkHealth, string) EvaluateCustom(IReadOnlyCollection<TargetCheckResult> custom)
    {
        if (custom.Count == 0)
        {
            return (NetworkHealth.Good, "Router and internet checks are disabled");
        }

        var reachable = custom.Count(r => r.Success);
        var total = custom.Count;

        return reachable switch
        {
            0 => (NetworkHealth.Offline, $"No custom targets reachable (0/{total})"),
            _ when reachable == total => (NetworkHealth.Good, $"All custom targets reachable ({reachable}/{total})"),
            _ => (NetworkHealth.Degraded, $"Some custom targets unreachable ({reachable}/{total})"),
        };
    }
}

        logger.LogInformation(

            }

        {
            display.Update(status);
        }
        catch (Exception ex) when (ex is IOException or ObjectDisposedException)

public interface INetworkConfigurationService

public sealed class NetworkConfigurationService(
    IGatewayDetector gatewayDetector,
    ITargetProber prober,
    IOptions<MonitorOptions> options,
    TimeProvider timeProvider,
    ILogger<NetworkConfigurationService> logger) : INetworkConfigurationService, IDisposable
{
    private const int RouterFailuresBeforeRedetect = 5;
    private static readonly TimeSpan RedetectCooldown = TimeSpan.FromSeconds(60);

    private readonly MonitorOptions _options = options.Value;
    private readonly SemaphoreSlim _lock = new(1, 1);
    private string? _routerAddress;
    private string? _internetTarget;
    private bool _initialized;
    private DateTimeOffset _lastRouterResolve = DateTimeOffset.MinValue;
    private int _consecutiveRouterFailures;

    public async Task<string?> GetRouterAddressAsync(CancellationToken cancellationToken)
    {
        await EnsureInitializedAsync(cancellationToken);
        await MaybeRedetectRouterAsync(cancellationToken);
        return _routerAddress;
    }

    public async Task<string> GetInternetTargetAsync(CancellationToken cancellationToken)
    {
        await EnsureInitializedAsync(cancellationToken);
        return _internetTarget ?? _options.InternetTarget;
    }

    public void ReportRouterCheckResult(bool reachable) =>
        _consecutiveRouterFailures = reachable ? 0 : _consecutiveRouterFailures + 1;

    public void Dispose() => _lock.Dispose();

    private async Task EnsureInitializedAsync(CancellationToken cancellationToken)
    {
        if (_initialized)
        {
            return;
        }

        await _lock.WaitAsync(cancellationToken);
        try
        {
            if (_initialized)
            {
                return;
            }

            _routerAddress = await ResolveRouterAddressAsync(cancellationToken);
            _lastRouterResolve = timeProvider.GetUtcNow();
            _internetTarget = await ResolveInternetTargetAsync(cancellationToken);
            _initialized = true;

            logger.LogInformation(
                "Network configuration initialized. Router: {Router}, Internet: {Internet}",
                _routerAddress ?? "(none)",
                _internetTarget);
        }
        finally
        {
            _lock.Release();
        }
    }

    private bool ShouldRedetectRouter() =>
        _options.IsRouterAutoDetect &&
        (_routerAddress is null || _consecutiveRouterFailures >= RouterFailuresBeforeRedetect) &&
        timeProvider.GetUtcNow() - _lastRouterResolve >= RedetectCooldown;

    private async Task MaybeRedetectRouterAsync(CancellationToken cancellationToken)
    {
        if (!ShouldRedetectRouter())
        {
            return;
        }

        await _lock.WaitAsync(cancellationToken);
        try
        {
            if (!ShouldRedetectRouter())
            {
                return;
            }

            _lastRouterResolve = timeProvider.GetUtcNow();
            var detected = await ResolveRouterAddressAsync(cancellationToken);
            if (string.IsNullOrEmpty(detected))
            {
                return;
            }

            if (!string.Equals(detected, _routerAddress, StringComparison.OrdinalIgnoreCase))
            {
                logger.LogInformation("Router address changed: {Old} -> {New}", _routerAddress ?? "(none)", detected);
            }

            _routerAddress = detected;
            _consecutiveRouterFailures = 0;
        }
        finally
        {
            _lock.Release();
        }
    }

    private async Task<string?> ResolveRouterAddressAsync(CancellationToken cancellationToken)
    {
        if (!_options.IsRouterAutoDetect)
        {
            return _options.RouterAddress;
        }

        var detected = gatewayDetector.DetectDefaultGateway();
        if (!string.IsNullOrEmpty(detected) && await IsReachableAsync(detected, cancellationToken))
        {
            return detected;
        }

        foreach (var gateway in gatewayDetector.CommonGatewayAddresses)
        {
            if (await IsReachableAsync(gateway, cancellationToken))
            {
                logger.LogInformation("Using fallback gateway: {Gateway}", gateway);
                return gateway;
            }
        }

        logger.LogWarning("No reachable gateway found. Router monitoring is disabled until one appears.");
        return null;
    }

    private async Task<string> ResolveInternetTargetAsync(CancellationToken cancellationToken)
    {
        if (!_options.EnableFallbackTargets)
        {
            return _options.InternetTarget;
        }

        foreach (var target in InternetTargets.Candidates(_options.InternetTarget))
        {
            if (await IsReachableAsync(target, cancellationToken))
            {
                return target;
            }
        }

        logger.LogWarning("No internet target is reachable. Using default: {Target}", _options.InternetTarget);
        return _options.InternetTarget;
    }

    private async Task<bool> IsReachableAsync(string address, CancellationToken cancellationToken) =>
        (await prober.ProbeAsync(MonitorTarget.Internet(address), 1, cancellationToken)).Success;
}

public sealed class NetworkMonitorService(
    INetworkConfigurationService configuration,

    IOptions<MonitorOptions> options,
    TimeProvider timeProvider,
    ILogger<NetworkMonitorService> logger) : INetworkMonitor

    public async Task<NetworkStatus> CheckAsync(CancellationToken cancellationToken)
    {
        var settings = options.Value;
        var targets = await BuildTargetsAsync(settings, cancellationToken);
        var results = new TargetCheckResult[targets.Count];

        await Parallel.ForEachAsync(
            Enumerable.Range(0, targets.Count),

        if (router is not null)
        {
            configuration.ReportRouterCheckResult(router.Success);
        }

        metrics.RecordCycle(results);

        var (health, message) = HealthEvaluator.Evaluate(router, internet, custom, settings);
        LogTransition(health, message);

        return new NetworkStatus(health, message, timeProvider.GetUtcNow(), results);
    }

    private async Task<List<MonitorTarget>> BuildTargetsAsync(MonitorOptions settings, CancellationToken cancellationToken)
    {
        var targets = new List<MonitorTarget>();

            await configuration.GetRouterAddressAsync(cancellationToken) is { Length: > 0 } routerAddress)
        {
            targets.Add(MonitorTarget.Router(routerAddress));
        }

        if (!settings.IsCheckDisabled(MonitorTarget.InternetName))
        {
            targets.Add(MonitorTarget.Internet(await configuration.GetInternetTargetAsync(cancellationToken)));
        }

        targets.AddRange(settings.CustomTargets
            .Where(t => t.Enabled && !string.IsNullOrWhiteSpace(t.Address) && !settings.IsCheckDisabled(t.Name))
            .Select(t => new MonitorTarget(t.Name, t.Address, TargetCategory.Custom)));

        return targets;

        {
            return;

        var level = health <= NetworkHealth.Poor ? LogLevel.Warning : LogLevel.Information;
        logger.Log(level, "Network status changed: {OldHealth} -> {NewHealth}: {Message}", _lastHealth?.ToString() ?? "Unknown", health, message);
        _lastHealth = health;
    }

using NetworkMonitor.Core.Models;

namespace NetworkMonitor.Core.Monitoring;

public readonly record struct PingStatistics(
    bool Success,
    long? MedianMs,
    long? MinMs,
    long? MaxMs,
    long? JitterMs,
    double PacketLossPercent,
    string? Error)
{
    public static PingStatistics From(IReadOnlyList<PingSample> samples)
    {
        if (samples.Count == 0)
        {
            return new(false, null, null, null, null, 100, "No ping results");
        }

        long[] latencies = [.. samples.Where(s => s.Success && s.RoundtripMs.HasValue).Select(s => s.RoundtripMs!.Value)];
        var loss = (double)(samples.Count - samples.Count(s => s.Success)) / samples.Count * 100;

        if (latencies.Length == 0)
        {
            return new(false, null, null, null, null, loss, samples[0].Error ?? "All pings failed");
        }

        long[] sorted = [.. latencies.Order()];
        return new(true, sorted[sorted.Length / 2], sorted[0], sorted[^1], Jitter(latencies), loss, null);
    }

    private static long? Jitter(long[] latencies)
    {
        if (latencies.Length < 2)
        {
            return null;
        }

        long sum = 0;
        for (var i = 1; i < latencies.Length; i++)
        {
            sum += Math.Abs(latencies[i] - latencies[i - 1]);
        }

        return (long)Math.Round((double)sum / (latencies.Length - 1), MidpointRounding.AwayFromZero);
    }
}

public interface ITargetProber
{

}

public sealed class TargetProber(
    IPingService pingService,
    IDnsResolver dnsResolver,
    IOptions<MonitorOptions> options,
    ILogger<TargetProber> logger) : ITargetProber
{
    private static readonly TimeSpan PingSpacing = TimeSpan.FromMilliseconds(50);

    public async Task<TargetCheckResult> ProbeAsync(MonitorTarget target, int pingCount, CancellationToken cancellationToken)
    {
        ArgumentNullException.ThrowIfNull(target);
        var settings = options.Value;

        try
        {
            DnsResult? dns = null;
            string? resolved = null;
            if (!IPAddress.TryParse(target.Address, out var address))
            {
                dns = await dnsResolver.ResolveAsync(target.Address, cancellationToken);
                var reported = settings.EnableDnsChecks ? dns : null;

                if (!dns.Success)
                {
                    return TargetCheckResult.Failed(target, $"DNS resolution failed: {dns.Error}", reported);
                }

                address = AddressSelector.Select(dns.Addresses, settings.EnableIPv6);
                if (address is null)
                {
                    return TargetCheckResult.Failed(target, "Host resolved only to IPv6 but IPv6 is disabled", reported);
                }

                dns = reported;
                resolved = address.ToString();
            }

            var samples = new List<PingSample>(pingCount);
            for (var i = 0; i < pingCount; i++)
            {
                if (i > 0)
                {
                    await Task.Delay(PingSpacing, cancellationToken);
                }

                samples.Add(await pingService.PingAsync(address, settings.TimeoutMs, cancellationToken));
            }

            var stats = PingStatistics.From(samples);
            return new TargetCheckResult(
                target,
                stats.Success,
                stats.MedianMs,
                stats.MinMs,
                stats.MaxMs,
                stats.JitterMs,
                stats.PacketLossPercent,
                dns,
                resolved,
                stats.Error);
        }
        catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
        {
            throw;
        }
        catch (Exception ex)
        {
            logger.LogWarning(ex, "Error checking {Name} ({Address})", target.Name, target.Address);
            return TargetCheckResult.Failed(target, ex.Message);
        }
    }
}

using NetworkMonitor.Core.Configuration;

namespace NetworkMonitor.Core.Storage;

public static class DataDirectory
{
    public static string Resolve(StorageOptions options)
    {
        ArgumentNullException.ThrowIfNull(options);

        if (!string.IsNullOrWhiteSpace(options.DataDirectoryOverride) && CanWrite(options.DataDirectoryOverride))
        {
            return options.DataDirectoryOverride;
        }

        var xdgDataHome = Environment.GetEnvironmentVariable("XDG_DATA_HOME");
        if (!string.IsNullOrEmpty(xdgDataHome) && CanWrite(xdgDataHome))
        {
            return Path.Combine(xdgDataHome, options.ApplicationName);
        }

        var localAppData = Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData);
        if (!string.IsNullOrEmpty(localAppData) && CanWrite(localAppData))
        {
            return Path.Combine(localAppData, options.ApplicationName);
        }

        var home = Environment.GetFolderPath(Environment.SpecialFolder.UserProfile);
        if (!string.IsNullOrEmpty(home))
        {
            var localShare = Path.Combine(home, ".local", "share");
            if (CanWrite(localShare) || CanWrite(home))
            {
                return Path.Combine(localShare, options.ApplicationName);
            }
        }

        var timestamp = DateTime.UtcNow.ToString("yyyyMMdd_HHmmss", CultureInfo.InvariantCulture);
        return Path.Combine(Environment.CurrentDirectory, $"{options.ApplicationName}_{timestamp}");
    }

    private static bool CanWrite(string path)
    {
        try
        {
            Directory.CreateDirectory(path);
            var probe = Path.Combine(path, $".write_test_{Guid.NewGuid():N}");
            File.WriteAllText(probe, "test");
            File.Delete(probe);
            return true;
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException or ArgumentException or NotSupportedException)
        {
            return false;
        }
    }
}

    public async Task SaveAsync(NetworkStatus status, CancellationToken cancellationToken)
    {
        ArgumentNullException.ThrowIfNull(status);
        try
        {
            await using var connection = await OpenAsync(cancellationToken);
            await using var transaction = (SqliteTransaction)await connection.BeginTransactionAsync(cancellationToken);

            await using var cycle = connection.Command(
                transaction,
                "INSERT INTO monitor_cycles (ts_ms, health, message) VALUES (@ts, @health, @message) RETURNING id",
                ("@ts", status.Timestamp.ToUnixTimeMilliseconds()),
                ("@health", (int)status.Health),
                ("@message", status.Message));
            var cycleId = Convert.ToInt64(await cycle.ExecuteScalarAsync(cancellationToken), CultureInfo.InvariantCulture);

            foreach (var result in status.Targets)
            {
                await InsertCheckAsync(connection, transaction, cycleId, result, cancellationToken);
            }

            await transaction.CommitAsync(cancellationToken);

            if (_options.PruneEveryNSaves > 0 && Interlocked.Increment(ref _saveCount) % _options.PruneEveryNSaves == 0)
            {
                await PruneAsync(connection, cancellationToken);
            }
        }
        catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
        {
            throw;
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "Failed to save status to SQLite");
        }
    }

    public async Task<IReadOnlyList<CheckRollup>> GetRollupsAsync(
        long fromBucketStartMsInclusive,
        long toExclusiveMs,
        int bucketMinutes,
        int limit,
        CancellationToken cancellationToken)
    {
        var minutes = Math.Max(1, bucketMinutes);
        await using var connection = await OpenAsync(cancellationToken);
        await using var command = connection.Command(
            null,
            """
            SELECT
                (mc.ts_ms - (mc.ts_ms % @bucket))                    AS bucket,
                t.name, t.address, t.category,
                COUNT(*)                                             AS samples,
                SUM(cr.success)                                      AS ok,
                AVG(CASE WHEN cr.success = 1 THEN cr.rtt_ms END)     AS avg_rtt,
                MIN(CASE WHEN cr.success = 1 THEN cr.rtt_min_ms END) AS min_rtt,
                MAX(CASE WHEN cr.success = 1 THEN cr.rtt_max_ms END) AS max_rtt,
                AVG(cr.jitter_ms)                                    AS avg_jitter,
                AVG(cr.dns_ms)                                       AS avg_dns,
                AVG(cr.loss_pct)                                     AS avg_loss
            FROM check_results cr
            JOIN monitor_cycles mc ON mc.id = cr.cycle_id
            JOIN targets t ON t.id = cr.target_id
            WHERE mc.ts_ms >= @from AND mc.ts_ms < @to
            GROUP BY bucket, t.id
            ORDER BY bucket, t.id
            LIMIT @limit
            """,
            ("@bucket", minutes * 60_000L),
            ("@from", fromBucketStartMsInclusive),
            ("@to", toExclusiveMs),
            ("@limit", limit));

        List<CheckRollup> rollups = [];
        await using var reader = await command.ExecuteReaderAsync(cancellationToken);
        while (await reader.ReadAsync(cancellationToken))
        {
            rollups.Add(new CheckRollup(
                BucketStartMs: reader.GetInt64(0),
                BucketMinutes: minutes,
                TargetName: reader.GetString(1),
                TargetAddress: reader.GetString(2),
                TargetCategory: reader.GetString(3),
                Samples: (int)reader.GetInt64(4),
                Ok: reader.IsDBNull(5) ? 0 : (int)reader.GetInt64(5),
                AvgRttMs: reader.IsDBNull(6) ? null : reader.GetDouble(6),
                MinRttMs: reader.IsDBNull(7) ? null : reader.GetInt64(7),
                MaxRttMs: reader.IsDBNull(8) ? null : reader.GetInt64(8),
                AvgJitterMs: reader.IsDBNull(9) ? null : reader.GetDouble(9),
                AvgDnsMs: reader.IsDBNull(10) ? null : reader.GetDouble(10),
                AvgLossPct: reader.IsDBNull(11) ? 0 : reader.GetDouble(11)));
        }

        return rollups;
    }

    public async Task<string?> GetSyncStateAsync(string key, CancellationToken cancellationToken)
    {
        ArgumentException.ThrowIfNullOrEmpty(key);
        await using var connection = await OpenAsync(cancellationToken);
        await using var command = connection.Command(null, "SELECT value FROM sync_state WHERE key = @key LIMIT 1", ("@key", key));

        await using var command = connection.Command(

            "INSERT INTO sync_state (key, value) VALUES (@key, @value) ON CONFLICT(key) DO UPDATE SET value = excluded.value",
            ("@key", key),
            ("@value", value));

    }

    private async Task<SqliteConnection> OpenAsync(CancellationToken cancellationToken)
    {
        var connection = new SqliteConnection(_connectionString);
        try
        {
            await connection.OpenAsync(cancellationToken);
            await using (var pragma = connection.Command(
                null,
                "PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL; PRAGMA busy_timeout=5000; PRAGMA temp_store=MEMORY;"))
            {
                await pragma.ExecuteNonQueryAsync(cancellationToken);
            }

            await EnsureSchemaAsync(connection, cancellationToken);
            return connection;
        }
        catch
        {
            await connection.DisposeAsync();
            throw;
        }
    }

    private async Task EnsureSchemaAsync(SqliteConnection connection, CancellationToken cancellationToken)
    {
        if (_initialized)
        {
            return;
        }

        await _initLock.WaitAsync(cancellationToken);
        try
        {
            if (_initialized)
            {
                return;
            }

            await using (var vacuum = connection.Command(null, "PRAGMA auto_vacuum=INCREMENTAL;"))
            {
                await vacuum.ExecuteNonQueryAsync(cancellationToken);
            }

            await using (var schema = connection.Command(null, SchemaSql))
            {
                await schema.ExecuteNonQueryAsync(cancellationToken);
            }

            _initialized = true;
        }
        finally
        {
            _initLock.Release();
        }
    }

    private async Task InsertCheckAsync(
        SqliteConnection connection,
        SqliteTransaction transaction,
        long cycleId,
        TargetCheckResult result,
        CancellationToken cancellationToken)
    {
        var targetId = await GetTargetIdAsync(connection, transaction, result.Target, cancellationToken);
        var success = result.Success;
        var error = result.Error ?? (result.Dns is { Success: false } dns ? dns.Error : null);

        await using var command = connection.Command(
            transaction,
            """
            INSERT OR REPLACE INTO check_results
                (cycle_id, target_id, success, rtt_ms, rtt_min_ms, rtt_max_ms, jitter_ms, dns_ms, loss_pct, resolved_ip, error_message)
            VALUES
                (@cycle, @target, @success, @rtt, @min, @max, @jitter, @dns, @loss, @resolved, @error)
            """,
            ("@cycle", cycleId),
            ("@target", targetId),
            ("@success", success ? 1 : 0),
            ("@rtt", success ? result.LatencyMs : null),
            ("@min", success ? result.MinLatencyMs : null),
            ("@max", success ? result.MaxLatencyMs : null),
            ("@jitter", success ? result.JitterMs : null),
            ("@dns", result.Dns?.ElapsedMs),
            ("@loss", Math.Clamp((int)Math.Round(result.PacketLossPercent, MidpointRounding.AwayFromZero), 0, 100)),
            ("@resolved", result.ResolvedAddress),
            ("@error", error));
        await command.ExecuteNonQueryAsync(cancellationToken);
    }

    private async Task<long> GetTargetIdAsync(
        SqliteConnection connection,
        SqliteTransaction transaction,
        MonitorTarget target,
        CancellationToken cancellationToken)
    {
        var key = (target.StorageCategory, target.Address);
        if (_targetIds.TryGetValue(key, out var cached))
        {
            return cached;
        }

        await using (var insert = connection.Command(
            transaction,
            "INSERT OR IGNORE INTO targets (name, address, category) VALUES (@name, @address, @category)",
            ("@name", target.Name),
            ("@address", target.Address),
            ("@category", target.StorageCategory)))
        {
            await insert.ExecuteNonQueryAsync(cancellationToken);
        }

        await using var select = connection.Command(
            transaction,
            "SELECT id FROM targets WHERE address = @address AND category = @category LIMIT 1",
            ("@address", target.Address),
            ("@category", target.StorageCategory));
        var id = Convert.ToInt64(await select.ExecuteScalarAsync(cancellationToken), CultureInfo.InvariantCulture);
        _targetIds.TryAdd(key, id);
        return id;
    }

    private async Task PruneAsync(SqliteConnection connection, CancellationToken cancellationToken)
    {
        var cutoffMs = _timeProvider.GetUtcNow().AddDays(-_options.RetentionDays).ToUnixTimeMilliseconds();
        await using (var delete = connection.Command(
            null,
            """
            DELETE FROM check_results
                WHERE cycle_id IN (SELECT id FROM monitor_cycles WHERE ts_ms < @cutoff);
            DELETE FROM monitor_cycles WHERE ts_ms < @cutoff;
            """,
            ("@cutoff", cutoffMs)))
        {
            var deleted = await delete.ExecuteNonQueryAsync(cancellationToken);
            if (deleted > 0)
            {
                _logger.LogDebug("Pruned {Count} old cycle/measurement rows", deleted);
            }
        }

        await using var vacuum = connection.Command(null, "PRAGMA incremental_vacuum;");
        await vacuum.ExecuteNonQueryAsync(cancellationToken);
    }
}

public sealed class DatabricksClient : IDatabricksClient, IDisposable
{
    private const string StatementsPath = "api/2.0/sql/statements";
    private static readonly TimeSpan PollInterval = TimeSpan.FromMilliseconds(1500);

    private readonly DatabricksSyncOptions _options;
    private readonly TimeProvider _timeProvider;
    private readonly ILogger<DatabricksClient> _logger;
    private readonly HttpClient _http;
    private readonly Uri? _statements;
    private readonly Uri? _tokenEndpoint;
    private readonly string _catalog;
    private readonly string _schema;
    private readonly SemaphoreSlim _tokenLock = new(1, 1);
    private string? _cachedToken;
    private DateTimeOffset _tokenExpiresAt = DateTimeOffset.MinValue;

    public DatabricksClient(IOptions<DatabricksSyncOptions> options, TimeProvider timeProvider, ILogger<DatabricksClient> logger)
    {
        ArgumentNullException.ThrowIfNull(options);
        _options = options.Value;
        _timeProvider = timeProvider;
        _logger = logger;
        _catalog = SqlIdentifier.Sanitize(_options.Catalog, "workspace", dashToUnderscore: true);
        _schema = SqlIdentifier.Sanitize(_options.Schema, "default", dashToUnderscore: true);

        if ((_options.HasToken || _options.HasOAuthCredentials) &&
            !string.IsNullOrWhiteSpace(_options.WarehouseId) &&
            TryBuildWorkspaceBase(_options.WorkspaceUrl, out var baseUri))
        {
            _statements = new Uri(baseUri, StatementsPath);
            _tokenEndpoint = new Uri(baseUri, "oidc/v1/token");
        }

        _http = SyncHttp.CreateClient(TimeSpan.FromSeconds(Math.Clamp(_options.RequestTimeoutSeconds, 60, 600)));
    }

    public bool IsConfigured => _statements is not null;

    private TimeSpan StatementDeadline => TimeSpan.FromSeconds(Math.Clamp(_options.RequestTimeoutSeconds, 30, 600));

    public async Task<bool> ExecuteAsync(IReadOnlyList<DatabricksStatement> statements, CancellationToken cancellationToken)
    {
        ArgumentNullException.ThrowIfNull(statements);
        if (_statements is null || statements.Count == 0 || await GetBearerTokenAsync(cancellationToken) is not { } token)
        {
            return false;
        }

        foreach (var statement in statements)
        {
            if (!await ExecuteOneAsync(statement, token, cancellationToken))
            {
                return false;
            }
        }

        return true;
    }

    public void Dispose()
    {
        _http.Dispose();
        _tokenLock.Dispose();
    }

    public static bool TryBuildWorkspaceBase(string? url, [NotNullWhen(true)] out Uri? baseUri)
    {
        baseUri = null;
        if (string.IsNullOrWhiteSpace(url))
        {
            return false;
        }

        var normalized = url.Trim();
        if (!normalized.Contains("://", StringComparison.Ordinal))
        {
            normalized = "https://" + normalized;
        }

        if (!SyncHttp.TryParseHttpUri(normalized, out var parsed))
        {
            return false;
        }

        baseUri = new UriBuilder(parsed.Scheme, parsed.Host, parsed.IsDefaultPort ? -1 : parsed.Port, "/").Uri;
        return true;
    }

    internal string BuildPayload(DatabricksStatement statement)
    {
        var root = new JsonObject
        {
            ["warehouse_id"] = _options.WarehouseId,
            ["catalog"] = _catalog,
            ["schema"] = _schema,
            ["statement"] = statement.Sql,
            ["wait_timeout"] = string.Create(CultureInfo.InvariantCulture, $"{_options.StatementWaitSeconds}s"),
            ["on_wait_timeout"] = "CONTINUE",
            ["format"] = "JSON_ARRAY",
            ["disposition"] = "INLINE",
        };

        if (statement.Parameters.Count > 0)
        {
            var parameters = new JsonArray();
            foreach (var p in statement.Parameters)
            {
                var node = new JsonObject { ["name"] = p.Name, ["type"] = p.Type };
                if (p.Value is not null)
                {
                    node["value"] = p.Value;
                }

                parameters.Add(node);
            }

            root["parameters"] = parameters;
        }

        return root.ToJsonString();
    }

    private async Task<bool> ExecuteOneAsync(DatabricksStatement statement, string token, CancellationToken cancellationToken)
    {
        var started = _timeProvider.GetTimestamp();
        try
        {
            var status = await SendAsync(HttpMethod.Post, _statements!, token, SyncHttp.Json(BuildPayload(statement)), cancellationToken);

            while (true)
            {
                switch (status.State)
                {
                    case "SUCCEEDED":
                        return true;
                    case "PENDING" or "RUNNING":
                        break;
                    default:
                        _logger.LogDebug("Databricks statement ended in state {State}: {Error}", status.State ?? "unknown", status.Error ?? "no error detail");
                        return false;
                }

                if (status.StatementId is not { } id || _timeProvider.GetElapsedTime(started) >= StatementDeadline)
                {
                    _logger.LogDebug("Databricks statement did not complete before the deadline");
                    if (status.StatementId is { } pending)
                    {
                        await SendAsync(HttpMethod.Post, StatementUri(pending, "/cancel"), token, null, cancellationToken);
                    }

                    return false;
                }

                await Task.Delay(PollInterval, _timeProvider, cancellationToken);
                status = await SendAsync(HttpMethod.Get, StatementUri(id, string.Empty), token, null, cancellationToken);
            }
        }
        catch (Exception ex) when (ex is not OperationCanceledException || !cancellationToken.IsCancellationRequested)
        {
            _logger.LogDebug(ex, "Databricks statement execution failed");
            return false;
        }
    }

    private Uri StatementUri(string statementId, string suffix) =>
        new($"{_statements!.AbsoluteUri}/{Uri.EscapeDataString(statementId)}{suffix}");

    private async Task<StatementStatus> SendAsync(HttpMethod method, Uri uri, string token, HttpContent? content, CancellationToken cancellationToken)
    {
        using var request = new HttpRequestMessage(method, uri) { Content = content };
        request.Headers.Authorization = new AuthenticationHeaderValue("Bearer", token);
        using var response = await _http.SendAsync(request, cancellationToken);

        if (!response.IsSuccessStatusCode)
        {
            _logger.LogDebug("Databricks returned HTTP {StatusCode} for {Method} {Path}", (int)response.StatusCode, method, uri.AbsolutePath);
            return new StatementStatus(null, null, null);
        }

        return StatementStatus.Parse(await response.Content.ReadAsStringAsync(cancellationToken));
    }

    private async Task<string?> GetBearerTokenAsync(CancellationToken cancellationToken)
    {
        if (_options.HasToken)
        {
            return _options.Token;
        }

        if (!_options.HasOAuthCredentials || _tokenEndpoint is null)
        {
            return null;
        }

        await _tokenLock.WaitAsync(cancellationToken);
        try
        {
            if (_cachedToken is null || _timeProvider.GetUtcNow() >= _tokenExpiresAt)
            {
                await RefreshTokenAsync(cancellationToken);
            }

            return _cachedToken;
        }
        finally
        {
            _tokenLock.Release();
        }
    }

    private async Task RefreshTokenAsync(CancellationToken cancellationToken)
    {
        _cachedToken = null;
        try
        {
            using var request = new HttpRequestMessage(HttpMethod.Post, _tokenEndpoint)
            {
                Content = new FormUrlEncodedContent(
                [
                    new("grant_type", "client_credentials"),
                    new("scope", string.IsNullOrWhiteSpace(_options.OAuthScope) ? "all-apis" : _options.OAuthScope),
                ]),
            };
            request.Headers.Authorization = new AuthenticationHeaderValue(
                "Basic",
                Convert.ToBase64String(Encoding.UTF8.GetBytes($"{_options.ClientId}:{_options.ClientSecret}")));

            using var response = await _http.SendAsync(request, cancellationToken);
            if (!response.IsSuccessStatusCode)
            {
                _logger.LogDebug("Databricks OAuth token endpoint returned HTTP {StatusCode}", (int)response.StatusCode);
                return;
            }

            var root = JsonNode.Parse(await response.Content.ReadAsStringAsync(cancellationToken));
            var accessToken = root?["access_token"]?.GetValue<string>();
            if (string.IsNullOrWhiteSpace(accessToken))
            {
                _logger.LogDebug("Databricks OAuth response did not contain an access token");
                return;
            }

            var expiresIn = int.TryParse(root?["expires_in"]?.ToString(), NumberStyles.Integer, CultureInfo.InvariantCulture, out var seconds) ? seconds : 3600;
            _cachedToken = accessToken;
            _tokenExpiresAt = _timeProvider.GetUtcNow().AddSeconds(Math.Max(30, expiresIn - 60));
        }
        catch (Exception ex) when (ex is not OperationCanceledException || !cancellationToken.IsCancellationRequested)
        {
            _logger.LogDebug(ex, "Databricks OAuth token request failed");
        }
    }

    private sealed record StatementStatus(string? State, string? StatementId, string? Error)
    {
        public static StatementStatus Parse(string body)
        {
            try
            {
                var root = JsonNode.Parse(body);
                return new StatementStatus(
                    root?["status"]?["state"]?.GetValue<string>()?.ToUpperInvariant(),
                    root?["statement_id"]?.GetValue<string>(),
                    root?["status"]?["error"]?["message"]?.GetValue<string>());
            }
            catch (Exception ex) when (ex is System.Text.Json.JsonException or InvalidOperationException or FormatException)
            {
                return new StatementStatus(null, null, null);
            }
        }
    }
}

using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
using NetworkMonitor.Core.Storage;

namespace NetworkMonitor.Core.Sync;

public sealed class RollupSyncService(
    IEnumerable<IRollupSink> sinks,
    IRollupStore store,
    TimeProvider timeProvider,
    ILogger<RollupSyncService> logger) : BackgroundService
{
    protected override Task ExecuteAsync(CancellationToken stoppingToken)
    {
        List<Task> loops = [];
        foreach (var sink in sinks)
        {
            if (sink.IsEnabled)
            {
                loops.Add(RunAsync(new RollupSyncer(sink, store, timeProvider, logger), stoppingToken));
            }
            else
            {
                logger.LogDebug("{Sink} is not configured; disabled", sink.Name);
            }
        }

        return Task.WhenAll(loops);
    }

    private async Task RunAsync(RollupSyncer syncer, CancellationToken stoppingToken)
    {
        var sink = syncer.Sink;
        var options = sink.Options;
        logger.LogInformation(
            "{Sink} enabled (every {Minutes} min, {Bucket}-min rollups) to {Destination}",
            sink.Name,
            options.SyncIntervalMinutes,
            options.BucketMinutes,
            sink.Destination);

        try
        {
            await Task.Delay(TimeSpan.FromSeconds(options.InitialDelaySeconds), timeProvider, stoppingToken);
            using var timer = new PeriodicTimer(TimeSpan.FromMinutes(options.SyncIntervalMinutes), timeProvider);

            do
            {
                try
                {
                    await syncer.SyncOnceAsync(stoppingToken);
                }
                catch (Exception ex) when (!stoppingToken.IsCancellationRequested)
                {
                    logger.LogDebug(ex, "{Sink} attempt failed; retrying next interval", sink.Name);
                }
            }
            while (await timer.WaitForNextTickAsync(stoppingToken));
        }
        catch (OperationCanceledException) when (stoppingToken.IsCancellationRequested)
        {
        }
    }
}

using System.Globalization;
using Microsoft.Extensions.Logging;
using NetworkMonitor.Core.Models;
using NetworkMonitor.Core.Storage;

namespace NetworkMonitor.Core.Sync;

public sealed class RollupSyncer(IRollupSink sink, IRollupStore store, TimeProvider timeProvider, ILogger logger)
{
    private bool _schemaEnsured;
    private bool _announced;

    public IRollupSink Sink => sink;

    public async Task<int> SyncOnceAsync(CancellationToken cancellationToken)
    {
        if (!sink.IsEnabled)
        {
            return 0;
        }

        if (!_schemaEnsured)
        {
            if (!await sink.EnsureSchemaAsync(cancellationToken))
            {
                return 0;
            }

            _schemaEnsured = true;
        }

        var options = sink.Options;
        var bucketMs = options.BucketMinutes * 60_000L;
        var nowMs = timeProvider.GetUtcNow().ToUnixTimeMilliseconds();
        var openBucketStart = nowMs - (nowMs % bucketMs);
        var batchSize = options.BatchSize;
        var maxRows = Math.Max(batchSize, options.MaxRowsPerSync);
        var checkpoint = await ReadCheckpointAsync(cancellationToken);
        var total = 0;

        while (total < maxRows && checkpoint < openBucketStart && !cancellationToken.IsCancellationRequested)
        {
            IReadOnlyList<CheckRollup> rows;
            try
            {
                rows = await store.GetRollupsAsync(checkpoint, openBucketStart, options.BucketMinutes, batchSize + 1, cancellationToken);
            }
            catch (Exception ex) when (ex is not OperationCanceledException)
            {
                logger.LogDebug(ex, "{Sink} could not read local rollups", sink.Name);
                break;
            }

            if (rows.Count == 0)
            {
                await WriteCheckpointAsync(openBucketStart, cancellationToken);
                break;
            }

            var truncated = rows.Count > batchSize;
            var (batch, next) = CompleteBuckets(truncated ? [.. rows.Take(batchSize)] : rows, truncated, bucketMs);

            if (!await sink.PushAsync(batch, timeProvider.GetUtcNow().ToUnixTimeMilliseconds(), cancellationToken))
            {
                break;
            }

            checkpoint = next;
            await WriteCheckpointAsync(checkpoint, cancellationToken);
            total += batch.Count;

            if (!truncated)
            {
                break;
            }
        }

        if (total > 0)
        {
            logger.Log(
                _announced ? LogLevel.Debug : LogLevel.Information,
                "{Sink} pushed {Count} rollup row(s) to {Destination}",
                sink.Name,
                total,
                sink.Destination);
            _announced = true;
        }

        return total;
    }

    internal static (IReadOnlyList<CheckRollup> Batch, long NextCheckpoint) CompleteBuckets(
        IReadOnlyList<CheckRollup> page,
        bool truncated,
        long bucketMs)
    {
        var lastBucket = page[^1].BucketStartMs;
        if (!truncated)
        {
            return (page, lastBucket + bucketMs);
        }

        CheckRollup[] complete = [.. page.Where(r => r.BucketStartMs < lastBucket)];
        return complete.Length == 0
            ? (page, lastBucket + bucketMs)
            : (complete, complete[^1].BucketStartMs + bucketMs);
    }

    private async Task<long> ReadCheckpointAsync(CancellationToken cancellationToken)
    {
        try
        {
            var raw = await store.GetSyncStateAsync(sink.CheckpointKey, cancellationToken);
            return long.TryParse(raw, NumberStyles.Integer, CultureInfo.InvariantCulture, out var value) ? value : 0;
        }
        catch (Exception ex) when (ex is not OperationCanceledException)
        {
            logger.LogDebug(ex, "{Sink} could not read its checkpoint; starting from 0", sink.Name);
            return 0;
        }
    }

    private async Task WriteCheckpointAsync(long value, CancellationToken cancellationToken)
    {
        try
        {
            await store.SetSyncStateAsync(sink.CheckpointKey, value.ToString(CultureInfo.InvariantCulture), cancellationToken);
        }
        catch (Exception ex) when (ex is not OperationCanceledException)
        {
            logger.LogDebug(ex, "{Sink} could not persist its checkpoint", sink.Name);
        }
    }
}

using System.Text;

namespace NetworkMonitor.Core.Sync;

public static class SqlIdentifier
{
    public static string Sanitize(string? name, string fallback, bool dashToUnderscore = false)
    {
        if (string.IsNullOrWhiteSpace(name))
        {
            return fallback;
        }

        var builder = new StringBuilder(name.Length);
        foreach (var ch in name)
        {
            if (char.IsLetterOrDigit(ch) || ch == '_')
            {
                builder.Append(ch);
            }
            else if (dashToUnderscore && ch == '-')
            {
                builder.Append('_');
            }
        }

        return builder.Length == 0 || char.IsDigit(builder[0]) ? fallback : builder.ToString();
    }
}

public interface IHranaClient

public sealed class HranaClient : IHranaClient, IDisposable
{
    private static readonly (string From, string To)[] SchemeAliases =
    [
        ("libsql://", "https://"),
        ("wss://", "https://"),
        ("ws://", "http://"),
    ];

    private readonly ILogger<HranaClient> _logger;
    private readonly HttpClient _http;
    private readonly Uri? _endpoint;
    private readonly string _authToken;

    public HranaClient(IOptions<RemoteSyncOptions> options, ILogger<HranaClient> logger)
    {
        ArgumentNullException.ThrowIfNull(options);
        var settings = options.Value;
        _logger = logger;
        _authToken = settings.AuthToken;
        _endpoint = !string.IsNullOrWhiteSpace(_authToken) && TryBuildPipelineEndpoint(settings.Url, out var endpoint) ? endpoint : null;
        _http = SyncHttp.CreateClient(TimeSpan.FromSeconds(Math.Clamp(settings.RequestTimeoutSeconds, 5, 300)));
    }

    public bool IsConfigured => _endpoint is not null;

    public async Task<bool> ExecuteAsync(IReadOnlyList<HranaStatement> statements, CancellationToken cancellationToken)
    {
        ArgumentNullException.ThrowIfNull(statements);
        if (_endpoint is null || statements.Count == 0)
        {
            return false;
        }

        try
        {
            using var request = new HttpRequestMessage(HttpMethod.Post, _endpoint)
            {
                Content = SyncHttp.Json(BuildPipeline(statements)),
            };
            request.Headers.Authorization = new AuthenticationHeaderValue("Bearer", _authToken);

            using var response = await _http.SendAsync(request, cancellationToken);
            if (!response.IsSuccessStatusCode)
            {
                _logger.LogDebug("Remote database returned HTTP {StatusCode}", (int)response.StatusCode);
                return false;
            }

            return AllSucceeded(await response.Content.ReadAsStringAsync(cancellationToken));
        }
        catch (Exception ex) when (ex is not OperationCanceledException || !cancellationToken.IsCancellationRequested)
        {
            _logger.LogDebug(ex, "Remote database pipeline request failed");
            return false;
        }
    }

    public void Dispose() => _http.Dispose();

    public static bool TryBuildPipelineEndpoint(string? url, out Uri? endpoint)
    {
        endpoint = null;
        if (string.IsNullOrWhiteSpace(url))
        {
            return false;
        }

        var normalized = url.Trim();
        foreach (var (from, to) in SchemeAliases)
        {
            if (normalized.StartsWith(from, StringComparison.OrdinalIgnoreCase))
            {
                normalized = string.Concat(to, normalized.AsSpan(from.Length));
                break;
            }
        }

        if (!SyncHttp.TryParseHttpUri(normalized, out var parsed))
        {
            return false;
        }

        endpoint = new UriBuilder(parsed)
        {
            Path = string.Concat(parsed.AbsolutePath.TrimEnd('/'), "/v2/pipeline"),
            Query = string.Empty,
            Fragment = string.Empty,
        }.Uri;
        return true;
    }

    internal static string BuildPipeline(IReadOnlyList<HranaStatement> statements)
    {
        var requests = new JsonArray();
        foreach (var statement in statements)
        {
            var args = new JsonArray();
            foreach (var arg in statement.Args)
            {
                args.Add(Encode(arg));
            }

            requests.Add(new JsonObject
            {
                ["type"] = "execute",
                ["stmt"] = new JsonObject { ["sql"] = statement.Sql, ["args"] = args },
            });
        }

        requests.Add(new JsonObject { ["type"] = "close" });
        return new JsonObject { ["requests"] = requests }.ToJsonString();
    }

    private static JsonObject Encode(SqlValue value) => value switch
    {
        long l => new JsonObject { ["type"] = "integer", ["value"] = l.ToString(CultureInfo.InvariantCulture) },
        double d => new JsonObject { ["type"] = "float", ["value"] = d },
        string s => new JsonObject { ["type"] = "text", ["value"] = s },
        null => new JsonObject { ["type"] = "null" },
    };

    private bool AllSucceeded(string body)
    {
        try
        {
            if (JsonNode.Parse(body)?["results"] is not JsonArray results)
            {
                _logger.LogDebug("Remote database response contained no results array");
                return false;
            }

            foreach (var result in results)
            {
                if (string.Equals(result?["type"]?.GetValue<string>(), "error", StringComparison.OrdinalIgnoreCase))
                {
                    _logger.LogDebug("Remote database statement error: {Message}", result?["error"]?["message"]?.GetValue<string>() ?? "unknown error");
                    return false;
                }
            }

            return true;
        }
        catch (Exception ex) when (ex is System.Text.Json.JsonException or InvalidOperationException or FormatException)
        {
            _logger.LogDebug(ex, "Could not parse remote database response");
            return false;
        }
    }
}

using System.Globalization;
using System.Text.Json;
using OpenTelemetry;
using OpenTelemetry.Metrics;

namespace NetworkMonitor.Core.Telemetry;

public sealed class FileMetricExporter : BaseExporter<Metric>
{
    private static readonly JsonSerializerOptions JsonOptions = new()
    {
        WriteIndented = true,
        PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
    };

    private readonly Lock _lock = new();
    private readonly RollingJsonArrayWriter _writer;

    public FileMetricExporter(FileExporterOptions options, TimeProvider timeProvider)
    {
        ArgumentNullException.ThrowIfNull(options);
        try
        {
            Directory.CreateDirectory(options.Directory);
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException)
        {
            options.Directory = Environment.CurrentDirectory;
        }

        _writer = new RollingJsonArrayWriter(options.Directory, options.RunId, options.MaxFileSizeBytes, timeProvider);
    }

    public override ExportResult Export(in Batch<Metric> batch)
    {
        try
        {
            lock (_lock)
            {
                foreach (var metric in batch)
                {
                    foreach (ref readonly var point in metric.GetMetricPoints())
                    {
                        _writer.Write(JsonSerializer.Serialize(ToRecord(metric, point), JsonOptions));
                    }
                }

                _writer.Flush();
            }

            return ExportResult.Success;
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"[FileMetricExporter] Export failed: {ex.Message}");
            return ExportResult.Failure;
        }
    }

    protected override bool OnShutdown(int timeoutMilliseconds)
    {
        lock (_lock)
        {
            _writer.Dispose();
        }

        return true;
    }

    protected override void Dispose(bool disposing)
    {
        if (disposing)
        {
            lock (_lock)
            {
                _writer.Dispose();
            }
        }

        base.Dispose(disposing);
    }

    private static object ToRecord(Metric metric, in MetricPoint point)
    {
        var tags = new Dictionary<string, string?>();
        foreach (var tag in point.Tags)
        {
            tags[tag.Key] = tag.Value?.ToString();
        }

        object? value = metric.MetricType switch
        {
            MetricType.LongSum => point.GetSumLong(),
            MetricType.DoubleSum => point.GetSumDouble(),
            MetricType.LongGauge => point.GetGaugeLastValueLong(),
            MetricType.DoubleGauge => point.GetGaugeLastValueDouble(),
            MetricType.Histogram => new { Count = point.GetHistogramCount(), Sum = point.GetHistogramSum() },
            _ => null,
        };

        return new
        {
            Timestamp = point.EndTime.ToString("O", CultureInfo.InvariantCulture),
            metric.Name,
            metric.Description,
            metric.Unit,
            Type = metric.MetricType.ToString(),
            Tags = tags,
            Value = value,
        };
    }
}

using System.Globalization;
using System.Text;

namespace NetworkMonitor.Core.Telemetry;

public sealed class RollingJsonArrayWriter(string directory, string runId, long maxFileSizeBytes, TimeProvider timeProvider) : IDisposable
{
    private StreamWriter? _writer;
    private DateTime _fileDate;
    private long _size;
    private int _fileNumber = -1;
    private bool _first = true;

    public string? CurrentPath { get; private set; }

    public void Write(string json)
    {
        ArgumentNullException.ThrowIfNull(json);
        var bytes = Encoding.UTF8.GetByteCount(json) + 2;
        var today = timeProvider.GetUtcNow().UtcDateTime.Date;

        if (_writer is null || _fileDate != today || _size + bytes > maxFileSizeBytes)
        {
            Open(today);
        }

        if (!_first)
        {
            _writer!.WriteLine(",");
        }

        _first = false;
        _writer!.Write(json);
        _size += bytes;
    }

    public void Flush() => _writer?.Flush();

    public void Dispose() => Close();

    private void Open(DateTime date)
    {
        Close();
        _fileNumber++;
        _fileDate = date;
        CurrentPath = Path.Combine(
            directory,
            _fileNumber == 0
                ? $"metrics_{runId}.json"
                : string.Create(CultureInfo.InvariantCulture, $"metrics_{runId}_{_fileNumber:D3}.json"));
        _writer = new StreamWriter(CurrentPath, append: false, Encoding.UTF8);
        _writer.WriteLine("[");
        _size = 2;
        _first = true;
    }

    private void Close()
    {
        if (_writer is null)
        {
            return;
        }

        _writer.WriteLine();
        _writer.WriteLine("]");
        _writer.Dispose();
        _writer = null;
    }
}
